# CS345_Assignment2

In Tutorial 2, we covered the initials of what could become a 2D Space Invader type of game.

In Assignment 2, you will make a 2D game by extending tutorial 2 by making significant changes. Below are some guidelines:

    Make significant changes to the game logic (25 points). Examples of some ideas:

        Game objects other than the player should be interactable, i.e., there should be physics (player pushing objects, for example)
        There should be new enemy types, possibly a boss fight.
        Add obstacles to the game, such as asteroids or blocks that limit navigation of the player.

        Enemies should get destroyed if hit more than a certain number of times, etc.
        You can attempt improving AI among enemy objects, to potentially attack the player in a smarter way, such as approaching from different directions.

    Make it a game which has a goal. (25 points)

        To give you some ideas as potential extensions:

            Collecting a certain number of collectibles?
            Reaching a certain score?

            Reaching a certain destination? etc.
    Make sure that the game is challenging and fun to play (20 points)

    Add a simple GUI. (20 points)

        To give you some ideas as potential extensions:

            keep a counter for the highest score?

            keep a leaderboard?

            make a pause screen/game over screen/intro screen etc. (you will need to Google GUI in Unity for this part

    Have a complete game loop. (20 points)

        That is to say, the game should have an end, and should have a replay option.

        Potentially, have more than one level for the game.

    You can use free assets that you find online

        Don’t forget to give credit to the source
